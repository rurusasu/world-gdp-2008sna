# Nix管理のAstro・Vite+環境 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Astro＋TypeScript＋Vite+の開発とPagesビルドを既存のNix環境で実行する。

**Architecture:** Pythonが公開データを生成し、Astroが既存画面を静的生成する。NixでNode.js/npmとPython/uvを供給し、言語別の依存は既存のuv.lockと新設package-lock.jsonで固定する。

**Tech Stack:** Nix Flakes、direnv、Python 3.15、uv、Node.js 24、npm、Astro、TypeScript、Vite+。

**Spec:** `docs/superpowers/specs/2026-10-18-nix-astro-design.md`

## Global Constraints

- Linux x86_64/aarch64のNix環境を維持する。
- Pythonの取得・集計方法と公開JSON/CSVの内容を変更しない。
- `/world-gdp-2008sna/`の公開パスと既存の表示・グラフ操作を維持する。
- ロックファイルから依存をインストールし、CIもNixを使用する。
- 既存専用チェックアウトのfeature branchで作業する。ユーザーの追加指定に従い、検証完了後に`origin/main`へpushする。

## Review Focus

- publicDirとoutDirの重複によるデータ消失を防ぐ。
- サブパスでJSON・Plotly・CSV・生成JS/CSSが404にならない。
- モジュール化後もPlotlyの読込順序とエラー表示が正しい。
- 欠測・価格基準未確認・期間変更で既存の数値処理を維持する。
- direnv再読込が依存の不一致を見逃さず、CIも同じツールを使用する。
